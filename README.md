# Statistics for Movement Science

*A Hands-On Guide with SPSS* — First Edition, by Ovande Furtado Jr., PhD (Cal State Northridge)

📖 **Read it free online:** https://drfurtado.github.io/sms/

A hands-on guide to statistics for movement science. Every concept is taught through examples from kinesiology, exercise science, and biomechanics, with step-by-step SPSS (version 31) tutorials, practice datasets, and labs.
