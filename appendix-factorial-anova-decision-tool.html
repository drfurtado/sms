Appendix F — Factorial ANOVA Decision Tool

NoteHow to use this tool
  1. Select the design type (Mixed, Between-Between, or Within-Within ANOVA).
  2. Indicate whether the interaction was significant in your SPSS output.
  3. If the interaction was not significant, select the significance status of each main effect.
  4. Specify the number of levels for each factor if you want tailored pairwise comparison guidance.
  5. Click Show decision path to generate your interpretation steps and APA-style reporting examples.

This tool is companion to ?sec-appendix-spss-factorial-anova (SPSS Tutorial: Factorial ANOVA).

Choose your scenario

Select the design, choose whether the interaction is significant, and then review the recommended interpretation steps.

Overview

Step 1
Check assumptions for the design.
Step 2
Test the interaction first.
Step 3
If significant, unpack with simple effects.
Step 4
If not significant, interpret main effects.

Make a selection on the left to generate a customised decision path.
